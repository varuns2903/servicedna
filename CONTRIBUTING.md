# Contributing

## Git Workflow
Please use conventional and meaningful commit messages:
- `feat(module): add new functionality`
- `fix(module): patch bug`
- `test(module): add tests`
- `refactor(module): change code structure without changing behavior`

## Definition of Done
1. Implementation exists.
2. Code compiles.
3. Tests exist and pass.
4. Security implications have been evaluated.
5. Functionality is documented.
