{{- if not .Values.secrets.existingSecret }}

Secrets were generated into {{ include "servicedna.secretName" . }} and are kept when the release
is uninstalled. Back it up with the database: without its database-password the data can't be
opened, and a new jwt-secret signs everyone out.
{{- end }}
{{- if or .Values.postgresql.enabled .Values.kafka.enabled .Values.tempo.enabled .Values.loki.enabled }}

Bundled datastores are single replicas — fine for evaluation and small teams. For production,
use managed Postgres/Redis/Kafka and your own Tempo/Loki (see the chart README).
{{- end }}
{{- if not .Values.smtp.host }}

No SMTP server (smtp.host): ServiceDNA can't send verification emails, so new accounts can't
sign in again once their first session ends. Set smtp.* before inviting people.
{{- end }}
{{- if not .Values.backup.enabled }}

Database backups are off: set backup.enabled=true, or use your database service's backups.
{{- end }}
